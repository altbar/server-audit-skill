# Аудит сервера силами своего ИИ-агента

Инструкция, по которой ваш агент сам проверяет ваш сервер или VPS и выдаёт понятный отчёт светофором: что торчит наружу, можно ли войти по паролю, где лежат ключи и токены и что из этого надо перевыпустить. Отдельный блок — про две истории октября 2026: дыры **PHP2Shell** в PHP и **взлом панелей VMmanager** у хостеров.

Работает с любой моделью: агент с доступом к серверу (Claude Code, Codex, Cursor, OpenCode, Hermes) проверяет сам, обычный чат (ChatGPT, DeepSeek, Claude в браузере) — вместе с вами, по шагам.

## Как запустить

**Одной фразой — любой агент.** Скажите ему:

```
Прочитай https://raw.githubusercontent.com/altbar/server-audit-skill/main/server-audit/SKILL.md
и проведи по нему аудит моего сервера. Сначала только смотри и покажи отчёт,
ничего не меняй без моего согласия.
```

Чат не открывает ссылки — скопируйте текст файла [`server-audit/SKILL.md`](server-audit/SKILL.md) и вставьте его вместе с этой фразой.

**В обычном чате без доступа к серверу** (ChatGPT, DeepSeek, Claude в браузере) — та же фраза. Чат будет давать команды по одному шагу, вы выполняете их в терминале сервера и вставляете ему ответ. Файлы с паролями и ключами целиком в чат не вставляйте: чат сам даст команду, которая показывает их обрезанными.

**Навыком в Claude Code** — чтобы он сам подхватывался на «проверь мой сервер»:

```bash
git clone https://github.com/altbar/server-audit-skill.git
mkdir -p ~/.claude/skills
cp -r server-audit-skill/server-audit ~/.claude/skills/
```

**В Hermes** — положить `server-audit/SKILL.md` в `~/.hermes/skills/server-audit/` и перезапустить.

## Перед запуском — две минуты

- **Сделайте снимок (snapshot) сервера** в кабинете хостера. Любая ошибка в настройках тогда чинится откатом, а не переустановкой.
- **Найдите аварийную консоль** в кабинете хостера — вход «с клавиатуры», мимо SSH. Она нужна, если сервер перестанет пускать.

## Что проверяется

| Шаг | Что смотрит агент |
|---|---|
| PHP2Shell | Версия PHP, откуда он поставлен, закрыты ли CVE-2026-109618 и CVE-2026-109619 |
| VMmanager | Был ли сервер у хостера на VMmanager в дни взлома, не оставили ли себе вход |
| Наружу | Какие порты видны из интернета, включая порты Docker в обход файрвола |
| Вход | Пускает ли SSH по паролю, кто и откуда входил |
| Защита | Файрвол, fail2ban, обновления безопасности |
| Секреты | Где на диске лежат ключи, токены и пароли и кто может их прочитать |
| Агент | Что ваш ИИ-агент может сделать без вашего подтверждения |

Агент сначала только смотрит. Чинит он по одному пункту и с вашего разрешения: файрвол включается только после разрешения SSH, а вход по паролю выключается последним — после того как вы вошли по ключу в новом окне. Найденные ключи он показывает обрезанными.

## Что случилось в октябре 2026

**PHP2Shell.** 21 октября закрыли две критические дыры в ядре PHP (CVSS 9.2). Через них можно выполнить свой код на чужом сервере без входа. Затронуты все версии начиная с 5.4. Нашли их с помощью ИИ. Исправленные версии: 8.5.12, 8.4.27, 8.3.36, 8.2.35. Подробнее — [Wiz](https://www.wiz.io/blog/php2shell-php-rce), [php.net](https://www.php.net/archive/2026.php).

**VMmanager.** С 11 по 17 октября злоумышленники взломали панели VMmanager 6 у десятков хостеров. Они выгрузили root-пароли из панелей, а у части хостеров читали диски клиентских серверов и забирали ключи, токены, `.env` и ключи ИИ-сервисов. Подробнее — [ForestsNet](https://forestsnet.cloud/ru/news/vmmanager-incident), [ISPsystem](https://www.ispsystem.ru/news/vulnerability-incident).

Если ваш сервер в эти дни жил у хостера на VMmanager, ключи и пароли на нём стоит считать утёкшими и перевыпустить. Удалить их из файла или переустановить сервер недостаточно.

## Чего этот аудит не делает

- Не ищет уязвимости в коде вашего сайта и не заменяет тест на проникновение.
- Не доказывает, что сервер не взломан. Он закрывает массовое: роботов-переборщиков, открытые порты, утёкшие ключи, известные дыры.
- Не заменяет менеджер паролей и двухфакторный вход в почте и кабинете хостера.

Команды рассчитаны на Ubuntu и Debian. На других системах агент подберёт аналоги команд и скажет, что проверить не смог.
